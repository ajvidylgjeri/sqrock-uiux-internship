# Eventa — Event Management Platform UI/UX

Sqrock IT Solutions UI/UX Internship — Phase 1, Task 3.

An event management platform UI delivered as a responsive HTML/CSS mockup.

## Screens / sections
Discovery (search + category filters + event grid) · Event detail with ticket-tier booking panel · "How it works" flow.

## Design system
Dark theme, violet→pink→cyan gradients, Sora, card-based layout, sticky booking panel.

Open `index.html` in a browser.
