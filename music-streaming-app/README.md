# Wavelength — Music Streaming App UI/UX

Sqrock IT Solutions UI/UX Internship — Phase 1, Task 1.

A 6-screen music streaming app concept, delivered as a live HTML/CSS mockup in phone frames.

## Screens
1. Splash / Welcome · 2. Login / Sign-up · 3. Home (playlists, recently played) · 4. Music Player · 5. Search (genres) · 6. Library

## Design system
Dark theme, mint (#1ed760) + violet accents, Plus Jakarta Sans, mobile-first, bottom tab navigation.

## View
Open `index.html` in a browser (all six screens render side by side).
