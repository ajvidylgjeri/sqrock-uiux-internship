# Sqrock IT Solutions — UI/UX Internship (Phase 1)

Three UI/UX design projects, delivered as **live, interactive HTML/CSS mockups** (viewable in any browser, no design tool needed). The phase requires any 3 projects.

| # | Project | Folder | Screens / scope |
|---|---------|--------|-----------------|
| 1 | Music Streaming App UI | [`music-streaming-app`](./music-streaming-app) | 6 phone screens: splash, login, home, player, search, library |
| 2 | Portfolio Website UI | [`portfolio-website`](./portfolio-website) | Full homepage: hero, about, skills, work, services, contact |
| 3 | Event Management Platform UI | [`event-management-platform`](./event-management-platform) | Discovery, event detail + booking, how-it-works |

## 🎨 About these deliverables
The task suggested Figma. These are delivered instead as **coded HTML/CSS designs** — a working, responsive representation of each interface that renders in any browser and can be screenshotted for submission. Each project is a single self-contained `index.html` with a consistent design system (colors, typography, spacing).

## 👀 View a project
Just open the `index.html` in a browser, or serve the folder:
```bash
cd music-streaming-app
python -m http.server 8000     # open http://localhost:8000
```

## 🧩 Design principles applied
Consistent color palette & typography · clear visual hierarchy · mobile-first layouts · reusable components · good spacing & alignment · accessible contrast.
