# Portfolio Website UI/UX

Sqrock IT Solutions UI/UX Internship — Phase 1, Task 2.

A modern, professional portfolio homepage design for a developer/designer, delivered as a responsive HTML/CSS mockup.

## Sections
Hero · About (with stats) · Skills · Selected work · Services · Contact · animated marquee.

## Design system
Warm light theme, coral (#ff5c35) accent, Space Grotesk, generous spacing, editorial layout.

## View
Open `index.html` in a browser.
